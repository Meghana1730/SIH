# Open review findings: job pipeline and synthetic data

A five-lens code review (extraction, ingestion, LLM layer, evaluation, synthetic data) with an
adversarial verifier for every finding, run on 2026-09-30. Only findings the verifier
CONFIRMED (reproduced) or judged PLAUSIBLE are listed. None of them affects the demo
analytics numbers (they come from the synthetic generator's ground truth).
