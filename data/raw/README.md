# Raw downloads (not committed to git)

Put original files here, untouched, in one folder per source ID from
`docs/DATA_SOURCE_INVENTORY.md`, for example `data/raw/S18/Electrician_CTS3.0_NSQF-4.pdf`.

Add a `SOURCE_NOTE.md` in each folder with: the URL you downloaded from, the date, and the
license/terms note. Everything in this folder except this README is ignored by git (files can be
large); share them through the team drive instead.
